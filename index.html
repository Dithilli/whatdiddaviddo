02 · The invisible corpus

One customer.
134 shared folders.
Four of them visible.

Unmounted shared folders never appear in the file-listing API — at any depth, under any flag. They were hidden from the folder picker and from sync, and nothing anywhere said so.

Returned by the API — 4 Existed, never mentioned — 130

Fixed by walking shared namespaces recursively, which also turned out to need about nine times fewer API calls than the naive version. Being correct was cheaper.

04 · Built twice

The connector
returned ghosts

Tuesday shipped an accounting integration — invoices, bills, credit memos, contacts, organisations. 2,473 lines. Then the vendor's connector started returning records with no identifiers at all, which is what it does instead of raising an auth error. It cannot tell a bad credential from an empty company.

05 · Whose fault

We were blaming
the wrong party

Send a malformed identifier and the API returned a gateway error — reporting our own validation bug as the upstream provider falling over. Calendar auth failures did the same thing. Three separate fixes this week came down to one sentence: stop calling our bugs someone else's outage.
