# whatdiddaviddo.com

A single-page scroll recap of one engineering week, republished weekly.
Static HTML, served from GitHub Pages.

- `/` — the current week (28 August – 4 September 2026)
- `/2026-08-28/` — week of 21–28 August
- `/2026-08-21/` — week of 15–21 August
- `/2026-08-14/` — week of 8–14 August (with `SCRIPT.md`, `COPY.md`, `BALLAD.md`)

Convention: when a new week is published, the outgoing `index.html` is archived
under its end date, and the new page's footer links to it.
